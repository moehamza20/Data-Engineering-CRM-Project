# Data-Engineering-CRM-Project
A data engineering project integrating PostgreSQL, MongoDB, ETL pipelines, and Streamlit to manage CRM data and visualize key metrics.

## Overview

A full-stack Data Engineering project that integrates PostgreSQL, MongoDB, ETL processes, and Streamlit into a unified CRM platform.

The project demonstrates how structured and semi-structured data can be collected, managed, transformed, and visualized through an interactive web application.

## Features

* User Authentication (Login & Registration)
* PostgreSQL Integration
* MongoDB Integration
* CRUD Operations
* ETL Processing
* Data Quality Checks
* Interactive Dashboard
* User Metrics & Analytics
* SQL and NoSQL Data Integration

## Technologies Used

* Python
* PostgreSQL
* MongoDB
* Streamlit
* Pandas
* SQL

## Architecture

PostgreSQL stores structured CRM data such as users, leads, courses, and agendas.

MongoDB stores semi-structured data including posts and additional user information.

An ETL process extracts data from both databases, transforms and cleans the records, then loads them into a unified analytical view.

The Streamlit dashboard provides real-time visibility into key metrics and business insights.
